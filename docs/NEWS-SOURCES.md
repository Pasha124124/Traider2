# Российские новостные источники

Модуль `src/news.js` собирает заголовки из лент РФ без API‑ключей и оценивает
их влияние на сценарий. Ключи не нужны: всё работает на обычных RSS.

## Источники по умолчанию

| Источник | Адрес | Проверен |
|---|---|---|
| Банк России | `cbr.ru/rss/RssNews` | да |
| Банк России · события | `cbr.ru/rss/eventrss` | да |
| Интерфакс | `interfax.ru/rss` | да |
| ТАСС | `tass.ru/rss/v2.xml` | да |
| Банки.ру | `banki.ru/xml/news.xml` | может быть недоступен |
| iXBT | `ixbt.com/export/news.rss` | может быть недоступен |

Недоступный источник не ломает ленту — он просто помечается как недоступный
в `data/news-impact.json`. Результат кэшируется на 15 минут.

Дополнительно `/api/news` подмешивает мировой GDELT, а в разделе «Новости»
настройка `?refresh=1` принудительно обновляет кэш.

## Необязательное расширение: Webz.io

Если задан ключ `WEBZ_API_TOKEN`, подключается Webz.io — у него шире покрытие
русскоязычных финансовых публикаций и есть поиск по смыслу. Ключ задаётся
в разделе «Подключения» или в переменных окружения.

```
WEBZ_API_TOKEN=...
```

## Как новости влияют на прогноз

Прямо по заголовкам, без нейросетей, и очень консервативно.

1. **Отбор.** Заголовок проходит дальше, только если содержит финансовую
   привязку: золото, курс, ключевая ставка, инфляция, санкции, сырьё,
   геополитика. Бытовая и политическая новость отбрасывается.
2. **Направление** задаётся явными правилами, а не общим словарём. Важный случай:
   «рубль подешевел» — это **плюс** для золота в рублях. Общие слова вроде
   «подешевел» без привязки к инструменту не применяются.
3. **Агрегация по источникам.** Перевес считается как среднее по изданиям,
   поэтому один агрегатор с двадцатью похожими заметками не перевесит
   три независимых источника.
4. **Порог.** Новости влияют на сценарий только при трёх заголовках с
   выраженным тоном из двух и более независимых источников.
5. **Влияние ограничено.** Сдвиг сводного импульса — максимум **15 баллов
   из 100**. Если новости противоречат цене, импульс нейтрализуется,
   а уверенность снижается на 12%.

Новости никогда не создают сигнал сами по себе: без свечей анализ не выполняется.

## Чего модуль не делает

- Не читает тексты статей — только заголовки.
- Не понимает сарказм, отрицания и пересказ прошлых новостей.
- Не отслеживает повторные публикации об одном событии.
- Не знает календарь событий ЦБ РФ и MOEX.

Из-за этого тональность — эвристика, а не фундаментальный анализ.
Направление, которое даёт один заголовок, почти всегда шум.
