# AU / Desk — локальный анализ GLDRUB_TOM

Браузерная аналитическая панель для **личного локального просмотра** биржевого золота MOEX (`GLDRUB_TOM`, руб./г). Панель сохраняет прогнозы и после окончания горизонта сверяет направление сценария с ближайшей доступной ценой.

> Это прототип количественного анализа, не торговый робот и не инвестиционная рекомендация. Он не выставляет ордера. Любые сценарии условные; историческая точность не доказывает прибыльность.

## Запуск на Windows без терминала

Убедитесь, что установлен Node.js 20 или новее, затем дважды щёлкните файл `Открыть AU Desk.bat` в папке проекта. Он запустит актуальную копию приложения в свёрнутом окне и откроет http://127.0.0.1:4174 в браузере. Порт 4174 выбран, чтобы не подключаться к старому процессу на 4173. Чтобы остановить сервер, закройте окно `AU Desk server`.

Если Node.js не установлен, сначала установите его с https://nodejs.org/ и повторно запустите BAT-файл. Зависимости npm проекту не нужны.

## Запуск из терминала (альтернатива)

```bash
npm start
```

Затем откройте http://127.0.0.1:4173 (или 4174, если запущен BAT-файл). Сервер привязан только к loopback-адресу компьютера.

```bash
npm test
```

## Источники

- При первом запуске панель использует **синтетические демо-свечи**, а не реальные котировки. Они отмечены как `DEMO` и не сохраняются в журнале как действительная рыночная история.
- В «Подключениях» можно задать read-only токен T‑Invest API. Сервер ищет `GLDRUB_TOM`, запрашивает минутные, часовые и дневные свечи (каждая выборка ограничена лимитами API) и объединяет их с локально накопленной историей. Live-цена и свечи появляются только при успешном WebSocket-подключении; иначе используется HTTP-снимок. После подключения обязательно проверьте символ, свежесть и цену через терминал брокера. Набор инструментов и исторические лимиты зависят от API-счёта.
- Если токен отсутствует, в настройках провайдера поддерживается MOEX ISS. Публичная ISS может возвращать данные с задержкой; интерфейс предупреждает не считать поток real-time без подтверждения подписки и лицензии.
- GDELT — бесплатный мировой агрегатор новостей; его поиск может быть неполным или недоступным. Новостные заголовки не входят в числовой торговый сигнал. Макрокалендарь автоматизированно не импортируется: панель даёт ссылки на официальный календарь ЦБ РФ и MOEX.
- Опциональный Yandex AI Studio объясняет уже рассчитанные индикаторы на русском языке. Он не создаёт цены, не контролирует сигналы и может ошибаться. Создайте AI Studio API key и Folder ID; подписка Claude Code не является таким ключом. В приложении можно проверить подключение перед включением объяснений.

## Настройка T‑Invest API

1. Выпустите отдельный токен с правами только на чтение в настройках Т‑Инвестиции → T‑Invest API.
2. В локальном интерфейсе откройте «Подключения» → T‑Инвестиции API, вставьте токен и нажмите «Проверить токен».
3. После успешной проверки выберите «Сохранить и подключить».
4. Секрет сохраняется на этом компьютере в `data/settings.json`; каталог `data/` исключён из Git. Не добавляйте его в репозиторий и не присылайте токен в чат.
5. T‑Invest API предназначен клиентам брокера и ограничен в ретрансляции данных. Используйте только для своего счёта и личного просмотра, проверьте текущие условия API и не публикуйте сервис.

## Настройка Yandex AI Studio

1. Создайте API-ключ AI Studio и узнайте идентификатор каталога в своём проекте Yandex Cloud.
2. В «Подключениях» укажите API-ключ. Folder ID для проекта предзаполнен как `b1gq3nq7ufds51e5gj9e`; замените его только если ключ принадлежит другому каталогу.
3. Используется URI модели `gpt://<folder_ID>/yandexgpt-5.1` (YandexGPT Pro 5.1; официальная таблица моделей: https://aistudio.yandex.ru/en/docs/ai-studio/concepts/generation/models).
4. При нажатии «Обновить анализ» приложение передаёт AI краткий локальный расчёт и до 10 заголовков новостей. Токен хранится на сервере и не раскрывается странице.

## Что умеет количественная часть

Использует изменение цены, SMA 20/50, RSI(14), MACD и недавний диапазон цены. Горизонты: 15 минут, 1 час, 4 часа, 1 день, 1 неделя и 1 месяц. Для каждого формируется «лонг», теоретический «шорт» либо ожидание, зона входа, стоп/уровень отмены и две цели.

Шорт всегда теоретический: панель не проверяет заём, маржинальные права, торговые лоты, комиссии, проскальзывание или возможность короткой продажи конкретного инструмента. При любом реальном действии эти условия должен отдельно проверить пользователь.

История прогнозов хранится локально в `data/forecasts.json`; каждому снимку присваивается исходный срок окончания. Оценка «совпал/не совпал» — только совпадение направления относительно входной цены. Она не оценивает отношение дохода к риску и не моделирует исполнение сделки. История может очиститься, если вы вручную удалите `data/`.

## Границы первой версии

- Не объединяет автоматически MOEX, XAU/USD и USD/RUB и не показывает глубину стакана.
- Не гарантирует полной и непрерывной минутной истории; 15м/1ч/4ч стабильнее проверять при достаточной плотности данных. Для горизонта месяца нужны отдельные свечи старшего интервала и история.
- Краткосрочные сценарии рассчитываются по минутным данным; недельный — по часовым, месячный — по дневным. Если до подключения накопилась короткая история, интерфейс снижает оценку уверенности и помечает малое покрытие.
- Автоматическая оценка прогнозов ждёт истечения горизонта и котировки не слишком далеко от его конца. Если источник не работал, рынок закрыт или история ограничена, результат остаётся ожидающим сверки; он не сравнивается с ценами, которые были до создания сценария.
- История цен от брокерского API, если сохраняется, должна использоваться согласно условиям брокера и биржи; при работе с личными данными не открывайте внешний доступ к локальному серверу.

## Безопасность

Сервер слушает только `127.0.0.1`, не использует торговые endpoints и не принимает сторонний origin через CORS. Локальные JSON-файлы секретов и истории создаются с правами файла `0600` в окружениях, которые поддерживают POSIX permissions. Доступ к компьютеру/профилю пользователя всё равно означает потенциальный доступ к этим файлам.
